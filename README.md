# Siddharth Gianchandani Portfolio

A static personal portfolio website for GitHub Pages. It is built with plain
HTML, CSS, and JavaScript, so there is no build step and no paid hosting needed.

## Files

- `index.html`: page content and section structure
- `assets/css/styles.css`: responsive layout and visual design
- `assets/js/main.js`: theme toggle, reveal animations, active navigation, and counter animation

## Update Content

Update professional experience, education, technical skills, profile details,
and contact links in `index.html`.
The LinkedIn button already points to:

`https://www.linkedin.com/in/siddharth-gianchandani`

## Host On GitHub Pages

1. Push this folder to a GitHub repository.
2. Open the repository on GitHub.
3. Go to `Settings` > `Pages`.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Select the `main` branch and the `/(root)` folder.
6. Save. GitHub will publish the site for free.
